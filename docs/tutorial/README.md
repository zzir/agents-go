# Tutorial

For a reader who wants to **learn by doing it once**: a path with one happy
ending, start to finish, no decisions to make along the way.

Start with [Running the workbench](workbench.md): a binary, one API key, a
first conversation with the Inspector open. The [Quickstart](quickstart.md)
is the SDK path, for embedding the same core in your own Go program.

The pages are listed below. The map of all four kinds of documentation is in
[`docs/`](../).
