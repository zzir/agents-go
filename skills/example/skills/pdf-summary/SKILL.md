# PDF summary

To summarize a PDF document:

1. Identify the document's major sections.
2. Extract the key claim or takeaway from each section.
3. Produce a concise bullet-point summary, one bullet per section, leading with the most important point.

Keep the summary under 200 words unless the user asks for more detail.
